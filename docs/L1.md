| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | ชุดรวมไลบรารีหลักสำหรับทดสอบแอปพลิเคชัน Spring Boot โดยดึงเครื่องมือทดสอบพื้นฐานมาให้พร้อมใช้งานในตัวเดียว|
